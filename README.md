# 🍳 Recipe App

Welcome to **Recipe App**, your ultimate kitchen companion for discovering, organizing, and cooking delicious meals! Whether you're looking for quick weeknight dinners, baking inspiration, or a way to save your family's secret recipes, this app has you covered.

---

## ✨ Features

*   **Smart Recipe Search:** Find recipes instantly by title, ingredients, cuisine, or dietary preferences.
*   **Step-by-Step Cooking Mode:** Distraction-free, chronological instructions with built-in timers.
*   **Digital Cookbook:** Save your favorite recipes, organize them into custom collections, and add personal notes.
*   **Automated Grocery Lists:** Add ingredients directly from any recipe into a consolidated shopping list.
*   **Nutritional Breakdown:** View detailed calorie counts and macronutrient info per serving.

---

## 🛠️ Tech Stack

*   **Frontend:** React / React Native
*   **Backend:** Node.js, Express
*   **Database:** MongoDB / PostgreSQL
*   **Authentication:** Firebase Auth / JSON Web Tokens (JWT)
